# Privacy and Anonymization

## Semantic rooms
Public labels should use anonymous IDs and functional categories such as `faculty_office`, `classroom`, `laboratory`, `corridor`, `stairs`, or `elevator`. Personal names should not be required benchmark labels.

## Wi-Fi
Retain only scientifically necessary fields. If BSSIDs/MAC addresses are needed for fingerprint consistency, release stable pseudonymous identifiers rather than raw identifiers when appropriate.

## Cellular/BTS
Review identifiers such as Cell ID/TAC/PCI and retain only what is necessary for reproducible positioning experiments. Consider stable pseudonyms for public release.

## Vision
Public images require review for faces, people, nameplates, monitors, documents, whiteboards, QR codes, phone numbers, and other identifying/sensitive information. Public images should be derived from reviewed/sanitized copies rather than raw originals.

## Maps
Publish research-oriented/sanitized maps. Remove personal names and operational/security-sensitive annotations not needed for indoor localization research.
