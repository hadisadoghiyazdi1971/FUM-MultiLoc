# FUM-MultiLoc Dataset Card

## Status
Specification-only release. No benchmark observations are included in v0.1.0.

## Planned modalities
- Wi-Fi
- IMU
- Vision
- Cellular/BTS
- Indoor maps
- Semantic location labels
- Spatial ground truth

## Planned environment
Faculty of Engineering environment, Ferdowsi University of Mashhad.

## Intended uses
Research and reproducible comparison of indoor localization methods, including single-modality, fusion, map-aware, and robustness experiments.

## Out-of-scope uses
The benchmark should not be presented as a surveillance dataset, a personnel-tracking system, or an authoritative source of operational building/network information.

## Known limitations
To be completed after inventory and quality assessment. At minimum the final card must report spatial coverage, temporal coverage, device diversity, participant diversity where relevant, missing data, sensor rate variability, calibration limitations, and ground-truth uncertainty.

## Data access
To be defined before first public release. Large binary data will be hosted outside the Git repository.
