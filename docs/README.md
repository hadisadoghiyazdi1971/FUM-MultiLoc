# Documentation

This folder contains the normative human-readable benchmark specification.

- `DATASET_CARD.md` — scope, intended use, limitations, and release status.
- `BENCHMARK_PROTOCOL.md` — tasks and evaluation rules.
- `COLLECTION_PROTOCOL.md` — how data collection must be documented.
- `COORDINATE_SYSTEM.md` — map/metric coordinate definitions.
- `GROUND_TRUTH_SPEC.md` — reference-point/trajectory truth representation.
- `TIMESTAMP_AND_SYNC.md` — timestamps and cross-modal synchronization.
- `PRIVACY_AND_ANONYMIZATION.md` — public-release privacy transformations.
- `SPLIT_POLICY.md` — leakage-resistant split policy.
- `DATA_HOSTING_AND_VERSIONING.md` — Git vs archive/data-hosting roles.
- `DATA_DICTIONARY.md` — field-level definitions.
